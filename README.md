# HUMIS Homepage Code

## Project Reflection

### Something I Learned

I am new to HTML and CSS, so a lot of the
code used to make this HUMIS homepage was
fun to write. I was a little familiar with
basic tags like headings and paragraphs,
but when I was introduced to other HTML
elements that work together as well as nest
within each other, I realized I could organize
a whole webpage. CSS was especially new to me,
and learning to use :root to create color variables
instead of typing the same color code multiple times
was interesting. I also learned more about certain
features when creating a layout, which are margins
and padding, that definitely affect the appearance
of a webpage.

### Future Designs

This project helped me better understand how to
code HTML and CSS files together. When I design
more websites in the future, I want to pay more
attention to how I add spacing and organize my
code in a way that's easy to understand. I think
this is important to consider because I often had
trouble with my website every time I made new changes.
